# Sistema de Gestão de Documentos

Aplicação web simples para enviar documentos (PDF, JPG ou PNG), consultá-los e registrar comentários. Case técnico da Resende Mori Hutchison Advocacia.

**Deploy público:** https://sistema-gestao-documentos.onrender.com

> Aviso: o serviço gratuito "dorme" após alguns minutos sem uso. A primeira abertura pode levar cerca de 1 minuto; depois responde normalmente.
